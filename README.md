# 강호유랑 안드로이드 앱 (APK) 만들기

게임 v1.0.4를 안드로이드 앱으로 감싼 프로젝트입니다.
- 앱을 켜면 바로 **전체 화면 가로 모드**로 실행됩니다 (상태 표시줄·내비게이션 바 숨김).
- 저장 데이터는 휴대폰 안에 저장됩니다. 앱을 지우면 함께 지워집니다.
- 뒤로 가기: 열린 창(가방·대화 등)이 있으면 닫고, 없으면 종료할지 묻습니다.
- 인터넷이 없어도 게임은 돌아갑니다. 붓글씨 글꼴만 기본 글꼴로 바뀝니다.

---

## 방법 1. GitHub이 대신 만들어 주기 (설치할 것 없음, 추천)

1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+ → New repository** → 이름 `gangho-yurang` → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 을 누르고,
   이 압축을 푼 폴더 **안의 내용 전체**(app, gradle, .github 폴더, settings.gradle 등)를 끌어다 놓은 뒤 **Commit changes**
   - `.github` 폴더가 숨김 폴더라 안 보이면, 탐색기에서 "숨김 항목 보기"를 켜고 함께 올려 주세요.
4. 저장소 위쪽 **Actions** 탭 → 「APK 빌드」가 자동으로 돌기 시작합니다 (약 3~5분).
5. 초록색 체크가 뜨면 그 항목을 눌러 아래 **Artifacts → gangho-yurang-apk** 를 내려받습니다.
6. 압축을 풀면 `app-release.apk` 가 나옵니다.

## 방법 2. 안드로이드 스튜디오로 만들기

1. https://developer.android.com/studio 에서 Android Studio를 설치합니다.
2. **Open** → 이 폴더(`gangho-android`)를 엽니다. 처음엔 필요한 파일을 내려받느라 몇 분 걸립니다.
3. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
4. 완료 알림의 **locate** 를 누르면 `app/build/outputs/apk/` 안에 APK가 있습니다.

---

## 휴대폰에 설치하기

1. APK 파일을 휴대폰으로 옮깁니다 (카카오톡 나에게 보내기, 구글 드라이브, USB 등).
2. 휴대폰에서 APK를 누르면 "출처를 알 수 없는 앱" 경고가 나옵니다 → **설정 → 이 출처 허용** → 설치
3. 홈 화면의 「강호유랑」 아이콘으로 실행합니다.

## 게임을 고친 뒤 앱 갱신하기

- `app/src/main/assets/index.html` 을 새 게임 파일로 바꾸고,
  `app/build.gradle` 의 `versionCode` 를 1 올립니다 (예: 104 → 105). 그다음 다시 빌드하면 됩니다.
- 같은 서명으로 빌드한 앱은 기존 앱 위에 덮어 설치되고, 저장 데이터도 유지됩니다.

## 참고 (플레이스토어 출시 시)

- 지금 APK는 **테스트 배포용 서명**입니다. 테스터에게 나눠 주는 데는 문제없습니다.
- 플레이스토어에 올리려면 정식 서명 키를 만들고 AAB(.aab) 형식으로 빌드해야 합니다. 필요할 때 따로 준비해 드릴게요.
